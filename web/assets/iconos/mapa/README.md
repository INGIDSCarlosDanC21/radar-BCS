- **Revisión:** cada archivo es un SVG de un solo trazo, sin scripts, enlaces, imágenes ni estilos incrustados.
- **Uso:** pines del mapa y controles de Pesca (`web/js/pesca.js`, `mapa-iconos.js`), niveles de Avisos (`web/js/avisos.js`) y la barra inferior (`web/index.html`). - **Se cargan en la web solo los que se usan;** los demás quedan en la carpeta y no pesan en la página.
