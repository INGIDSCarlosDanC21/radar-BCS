# Google Drive del proyecto

GitHub guarda código y coordinación. **Google Drive** guarda lo pesado, que no se sube al repositorio (el `.gitignore` bloquea `.tif`, `.nc`, `.hdf`, `.h5`, `.mp4`, `.glb`, `.wav`).

Enlace: https://drive.google.com/drive/folders/1l-NtKxmMq1Mjp1Cxbc945N97wyyVGMZa

## Estructura

| Carpeta | Contenido |
|---|---|
| `datasets/` | Descargas de NASA (MODIS, POWER, GRACE/GLDAS, NASADEM) y derivados grandes |
| `video/` | Grabaciones de la demo, versiones editadas, subtítulos |
| `3d/` | Modelos 3D (relieve de La Paz) |
| `audio/` | Narración y música (con licencia registrada) |
| `documentos/` | PDFs y documentos de apoyo |

Todo lo que se use en el proyecto se registra también en `docs/RECURSOS.md`.
